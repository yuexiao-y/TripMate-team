# TripMate 团队版

TripMate 是微信小程序旅行助手，支持智能规划行程、行程管理、交通记录、预算记账、吃喝记录、旅行打卡和出行清单。首页汇总行程与记录数据。

## 本地运行

1. 使用微信开发者工具导入本目录，项目类型选择“小程序”。
2. 根据自己的开发环境配置小程序 AppID 和云开发环境。项目的本机设置保存在被忽略的 `project.private.config.json` 中。
3. 编译并预览。云端 AI 不可用时，规划功能会回退到本地规则引擎。

项目没有 npm 安装步骤。页面入口在 `app.json`，功能代码位于 `pages/`、`components/` 和 `utils/`。

详细设计见 [4+1 架构文档](docs/architecture-4plus1.md)。
